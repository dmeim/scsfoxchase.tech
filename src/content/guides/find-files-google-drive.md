Looking for a file in Google Drive? Start with search and filters. If it still does not show up, work through the checklist at the end.<sup class="guide-fn"><a href="#source-1">1</a></sup>

Tip: If you have access to Gemini in Workspace features, you can type a natural-language question in the search bar (for example, “Summarize the project timeline”). An AI Overview can appear at the top of your results with a summary and links to the source files.<sup class="guide-fn"><a href="#source-1">1</a></sup>

## Search and filter (computer)

On a Chromebook, desktop, or laptop, open [drive.google.com](https://drive.google.com).<sup class="guide-fn"><a href="#source-1">1</a></sup>

You can narrow results with **filter chips**, typed search terms, or both. Filter chips include:

- **Type**
- **People**
- **Modified**

Those filters also appear inside the search bar. You can pick one, or start typing (for example, “doc”) to see a suggested chip such as Documents.<sup class="guide-fn"><a href="#source-1">1</a></sup>

After you select a filter chip:

1. Pick your file from the filtered list in the search box, or
2. Press **Enter** for more results.

You can combine a chip with more text. Example: choose **Type = Presentations**, then type **Client** to see presentations that include that word.<sup class="guide-fn"><a href="#source-1">1</a></sup>

- To remove one chip: click **Remove** on the right of the chip.
- To clear all chips: click **Clear filters**.

Results sort by relevance by default. Click a column header to sort differently; choose **More sorting options** to return to relevance.<sup class="guide-fn"><a href="#source-1">1</a></sup>

## Search on Android

Drive search covers titles and content of files you have permission to access.<sup class="guide-fn"><a href="#source-2">2</a></sup>

**Start with text**

1. Open the **Google Drive** app.
2. At the top, tap **Search in Drive**.
3. Type a word or phrase. Drive may suggest filter chips for Type, People, Date Modified, and more.
4. Select a chip to narrow the list, or tap a chip and then **Clear** to remove it.<sup class="guide-fn"><a href="#source-2">2</a></sup>

**Start with filter chips**

1. Open the **Google Drive** app.
2. At the top, tap **Search in Drive**.
3. Select a filter chip for **Type**, **People**, or **Modified**.
4. Optionally add a keyword.
5. To remove a chip, tap it, then tap **Clear**.<sup class="guide-fn"><a href="#source-2">2</a></sup>

**Search inside a folder**

1. Open the folder.
2. Below the search bar, select the folder filter chip to limit the search to that folder.
3. Enter your search term.<sup class="guide-fn"><a href="#source-2">2</a></sup>

## Useful advanced search operators

Not all examples work on every device. Type these in the Drive search bar.<sup class="guide-fn"><a href="#source-1">1</a></sup>

| Operator | What it finds | Example |
| --- | --- | --- |
| Quotes | Exact word or phrase | `"match this phrase exactly"` |
| Minus sign | Exclude a word | `salsa -dancing` |
| `owner:` | Files owned by a person | `owner:bob@gmail.com` |
| `pendingowner:me` | Files you are a pending owner of | `pendingowner:me` |
| `type:` | File type (document, spreadsheet, PDF, and more) | `type:document` |
| `before:` / `after:` | Modified before or after a date (`YYYY-MM-DD`) | `before:2021-05-02` |
| `title:` | Match in the title | `title:Conference 2021` |
| `is:starred` | Starred items | `is:starred` |
| `is:trashed` | Items in Trash | `is:trashed` |
| `is:unorganized` | Files that lost their folder | `is:unorganized owner:me` |

Other operators Google documents include `to:`, `from:`, `creator:`, `app:`, `sharedwith:`, `createdbefore:` / `createdafter:`, and `followup:`.<sup class="guide-fn"><a href="#source-1">1</a></sup>

## Find files by size (computer)

1. Go to [drive.google.com](https://drive.google.com).
2. On the left, click **Storage**.
3. On the right, click **Storage used** to sort by size.
4. Click **Storage used** again to reverse the order.<sup class="guide-fn"><a href="#source-1">1</a></sup>

## If you still cannot find the file

Search first. If the file is still missing, it may have been moved or deleted by you or by someone who shared it with you.<sup class="guide-fn"><a href="#source-4">4</a></sup>

### Check Trash

**Computer**

1. Go to [drive.google.com](https://drive.google.com).
2. On the left, click **Trash**.
3. Right-click the file → **Restore**.<sup class="guide-fn"><a href="#source-4">4</a></sup>

**Android**

1. Open the **Google Drive** app.
2. At the top left, tap **Menu** → **Trash**.
3. Next to the file, tap **Menu** → **Restore**.<sup class="guide-fn"><a href="#source-5">5</a></sup>

**iPhone and iPad**

1. Open the **Google Drive** app.
2. At the top left, tap **Menu** → **Trash**.
3. Next to the file, tap **Menu** → **Restore**.<sup class="guide-fn"><a href="#source-6">6</a></sup>

Files stay in Trash for **30 days**, then they are deleted forever.<sup class="guide-fn"><a href="#source-4">4</a></sup>

For full restore steps and platform GIFs, see [Recover a deleted file in Google Drive](/guide/recover-deleted-file-google-drive).

### Check activity (computer)

1. Go to [drive.google.com](https://drive.google.com).
2. On the left, click **My Drive**.
3. At the top right, click **Info** → **Activity**.

If you own the file or folder, recent activity may show where it went.<sup class="guide-fn"><a href="#source-4">4</a></sup>

On a phone or tablet, Google’s help notes that you can open drive.google.com in a mobile browser, request the desktop site, and check activity there.<sup class="guide-fn"><a href="#source-5">5</a></sup>

### Confirm the correct Google Account

Many people have more than one Google Account (for example, school and personal). Make sure you are signed into the account where you last used the file.<sup class="guide-fn"><a href="#source-4">4</a></sup>

### Shared file access

If a shared file is gone, the owner may have changed permissions. Common cases:<sup class="guide-fn"><a href="#source-4">4</a></sup>

- Access to the parent folder was removed.
- The file was moved to a folder you cannot access.
- The file is in a limited-access folder (you may see the folder grayed out).

To find limited-access items where you have Viewer access, search for `is:limited_access`.<sup class="guide-fn"><a href="#source-4">4</a></sup>

If you should still have access, ask the owner to check permissions on the file or its folder.<sup class="guide-fn"><a href="#source-4">4</a></sup>

### Shared drives

Items you create, upload, or move into a shared drive belong to that Workspace domain. If your access to the shared drive is removed, you lose access to those items. Ask the person who shared it to restore access or share again.<sup class="guide-fn"><a href="#source-4">4</a></sup>

### Unorganized files

A file you own can lose its folder if:

- You created it in someone else’s folder and they deleted that folder, or
- You shared a folder and someone removed your file from it.

The file is not deleted; it moves to **My Drive**.<sup class="guide-fn"><a href="#source-4">4</a></sup>

1. In Drive search, enter `is:unorganized`.
2. When you find the file, move it into a folder in **My Drive** so it is easier to find later.<sup class="guide-fn"><a href="#source-4">4</a></sup>

If you still cannot locate the file, submit a Help form so staff can follow up.
