Folders, stars, colors, and shortcuts help you keep Drive readable. There is no single “correct” layout — start simple and adjust as you go.<sup class="guide-fn"><a href="#source-1">1</a></sup>

Looking for a missing file instead? See [Find files in Google Drive](/guide/find-files-google-drive). Sharing with others is covered in [Share files and folders in Google Drive](/guide/share-files-google-drive).

## Tips that work on any device

- Nest folders for projects, then smaller folders for topics or assignments.<sup class="guide-fn"><a href="#source-1">1</a></sup>
- Use clear names (dates, project titles, or keywords).<sup class="guide-fn"><a href="#source-1">1</a></sup>
- Color-code folders for similar work.<sup class="guide-fn"><a href="#source-1">1</a></sup>
- Star files you need often; starred items show up in one place.<sup class="guide-fn"><a href="#source-1">1</a></sup>

If you organize a lot of files at once, changes can take time to appear.<sup class="guide-fn"><a href="#source-1">1</a></sup>

## Computer (including Chromebook)

### Create a folder

1. Go to [drive.google.com](https://drive.google.com).
2. On the left, click **New** → **Folder**.
3. Enter a name.
4. Click **Create**.<sup class="guide-fn"><a href="#source-1">1</a></sup>

### Move a file or folder

You need permission to move from the source to the destination. If you do not, Drive creates a **shortcut** in the destination instead of moving the file.<sup class="guide-fn"><a href="#source-1">1</a></sup>

**Right-click move**

1. Go to [drive.google.com](https://drive.google.com).
2. Right-click the item.
3. Click **Organize** → **Move**.
4. Select or create a folder.
5. Click **Move**.<sup class="guide-fn"><a href="#source-1">1</a></sup>

**Drag**

1. Drag the item onto a folder and release.<sup class="guide-fn"><a href="#source-1">1</a></sup>

**Chrome keyboard shortcuts**

1. Select a file.
2. Press **Ctrl + X** to cut.
3. Open the destination.
4. Press **Ctrl + V** to paste, or **Ctrl + Shift + V** to paste a shortcut.<sup class="guide-fn"><a href="#source-1">1</a></sup>

### Make a copy of a file

You can copy files (not folders). On Chrome:

1. Right-click a file → **Make a copy**, or
2. Select the file, press **Ctrl + C**, go to the destination, press **Ctrl + V**.<sup class="guide-fn"><a href="#source-1">1</a></sup>

This is not available in Drive for desktop.<sup class="guide-fn"><a href="#source-1">1</a></sup>

### Change folder color

Colors you set apply only to **your** view of Drive.<sup class="guide-fn"><a href="#source-1">1</a></sup>

1. Right-click the folder.
2. Click **Organize**, then choose a color under **Folder color**.<sup class="guide-fn"><a href="#source-1">1</a></sup>

### View and reorder

You can use **list** or **grid** layout from the toolbar.<sup class="guide-fn"><a href="#source-4">4</a></sup>

Sorting is available in **My Drive** (not on Home or Recent).<sup class="guide-fn"><a href="#source-4">4</a></sup>

**List view**

1. Open **My Drive**.
2. Click a column header to sort.
3. Click the up/down arrow to reverse the order.<sup class="guide-fn"><a href="#source-4">4</a></sup>

**Grid view**

1. Open **My Drive**.
2. At the top right, click the current sort title (for example **Name** or **Modified**).
3. Choose a sort option; use the arrow to reverse.<sup class="guide-fn"><a href="#source-4">4</a></sup>

In My Drive, Shared with me, and Starred, you can show folders on top or mixed with files: click **Sort**, then **On top** or **Mixed with files**.<sup class="guide-fn"><a href="#source-4">4</a></sup>

To turn off hover preview cards: **Settings** → **Settings** → **General** → uncheck **Show details card when hovering on a file or folder icon**.<sup class="guide-fn"><a href="#source-4">4</a></sup>

### Spot possible duplicates

Sort by name in list view, or search for names/types you suspect are duplicated.<sup class="guide-fn"><a href="#source-1">1</a></sup>

## Android

### Create a folder

1. Open the **Google Drive** app.
2. At the bottom right, tap **Add**.
3. Tap **Folder**.
4. Name the folder.
5. Tap **Create**.<sup class="guide-fn"><a href="#source-2">2</a></sup>

### Move a file or folder

Without move permission, Drive creates a shortcut instead.<sup class="guide-fn"><a href="#source-2">2</a></sup>

1. Open the **Google Drive** app.
2. Next to the item, tap **More** → **Move**.
3. Choose a folder, then tap **Move here** (or **New folder**).<sup class="guide-fn"><a href="#source-2">2</a></sup>

On Android you can also open two Drive windows side by side (same account), long-press an item, and drag it to the new location.<sup class="guide-fn"><a href="#source-2">2</a></sup>

### Change folder color

1. Next to the folder, tap **More** → **Change color**.
2. Choose a color.<sup class="guide-fn"><a href="#source-2">2</a></sup>

### View and sort

Switch list/grid from the toolbar.<sup class="guide-fn"><a href="#source-5">5</a></sup>

1. Open Drive → tap **Files**.
2. Under **My Drive**, tap the current **Sort by** method.
3. To reverse the sort, tap the arrow next to it.<sup class="guide-fn"><a href="#source-5">5</a></sup>

## iPhone and iPad

### Create a folder

1. Open the **Google Drive** app.
2. At the bottom right, tap **Add**.
3. Tap **Folder**.
4. Name the folder.

### Move a file or folder

Without move permission, Drive creates a shortcut instead.<sup class="guide-fn"><a href="#source-3">3</a></sup>

1. Open the **Google Drive** app.
2. Next to the item, tap **More** → **Move** (scroll if needed).
3. Choose a folder, then tap **Move here** (or **New folder**).<sup class="guide-fn"><a href="#source-3">3</a></sup>

### Change folder color

1. Next to the folder, tap **More** → **Change color**.
2. Choose a color.<sup class="guide-fn"><a href="#source-3">3</a></sup>

### View and sort

Switch list/grid from the toolbar.<sup class="guide-fn"><a href="#source-6">6</a></sup>

1. Open Drive → tap **Files**.
2. Under **My Drive**, tap the current **Sort by** method.
3. To reverse the sort, tap the arrow next to it.<sup class="guide-fn"><a href="#source-6">6</a></sup>

## Shortcuts

A **shortcut** is a link to another file or folder. It points at the original so you keep one real copy while opening it from more than one place.<sup class="guide-fn"><a href="#source-8">8</a></sup>

- You can use shortcuts in My Drive or a shared drive.<sup class="guide-fn"><a href="#source-8">8</a></sup>
- Shortcut titles are visible to everyone who can see that folder or drive.<sup class="guide-fn"><a href="#source-8">8</a></sup>
- Not everyone who sees the shortcut can open the original — permissions stay on the original file.<sup class="guide-fn"><a href="#source-8">8</a></sup>
- Creating a shortcut does **not** automatically change sharing on the original.<sup class="guide-fn"><a href="#source-8">8</a></sup>
- You can make up to **500** shortcuts per item yourself; an item can have up to **5,000** shortcuts total.<sup class="guide-fn"><a href="#source-8">8</a></sup>
- You cannot create a shortcut to another shortcut (you can copy a shortcut).<sup class="guide-fn"><a href="#source-8">8</a></sup>

### Create a shortcut (computer)

1. Go to [drive.google.com](https://drive.google.com).
2. Right-click the file or folder.
3. Click **Organize** → **Add shortcut**.
4. Choose where the shortcut should live.
5. Click **Add shortcut**.<sup class="guide-fn"><a href="#source-1">1</a></sup>

On Chrome you can also select the file, press **Ctrl + C**, go to the destination, and press **Ctrl + Shift + V**.<sup class="guide-fn"><a href="#source-8">8</a></sup>

### Delete a shortcut

Right-click (computer) or use **More** (mobile) → **Remove**. Deleting a shortcut does **not** delete the original file.<sup class="guide-fn"><a href="#source-1">1</a></sup><sup class="guide-fn"><a href="#source-8">8</a></sup>

If you created a shortcut inside someone else’s folder, you may not be able to delete it.<sup class="guide-fn"><a href="#source-9">9</a></sup>

### Broken shortcuts

A shortcut breaks if you lack permission, or the original is in Trash or deleted. Restore the original or ask the owner for access.<sup class="guide-fn"><a href="#source-8">8</a></sup>

### When Drive replaced multi-location files with shortcuts

Drive replaced most “same file in many folders” setups with shortcuts so one original stays in one place.<sup class="guide-fn"><a href="#source-11">11</a></sup>

To find items that were replaced, search: `is:replaced`.<sup class="guide-fn"><a href="#source-11">11</a></sup>

## Activity and versions (computer)

Activity can show edits, comments, renames, moves, uploads, and sharing changes.<sup class="guide-fn"><a href="#source-7">7</a></sup>

1. Go to [drive.google.com](https://drive.google.com).
2. Open **My Drive**.
3. At the top right, click **Info**.
4. Open **Activity**, or select a specific file/folder first.<sup class="guide-fn"><a href="#source-7">7</a></sup>

For non-Google files stored in Drive, you can keep and restore recent versions (use **Keep forever** if you need an older version to stay). Version history for Docs, Sheets, and Slides works differently inside those apps.<sup class="guide-fn"><a href="#source-7">7</a></sup>

To see when a file was added: right-click → **File information** → **Details**, then check **Created**.<sup class="guide-fn"><a href="#source-7">7</a></sup>

## Notifications (computer)

You can get notified when someone shares with you, mentions you, or requests access to a file you own.<sup class="guide-fn"><a href="#source-12">12</a></sup>

1. Go to [drive.google.com](https://drive.google.com).
2. Click **Settings** → **Settings**.
3. Open **Notifications**.
4. Check or uncheck the options you want.<sup class="guide-fn"><a href="#source-12">12</a></sup>

Change these on each computer you use.<sup class="guide-fn"><a href="#source-12">12</a></sup>

## Labels (work or school)

If your organization uses Drive labels, an administrator creates them. You may apply up to **5** labels per file when you have access and edit permission.<sup class="guide-fn"><a href="#source-13">13</a></sup>

1. Right-click a file → **Labels** → **Apply labels**.
2. Choose the label (and any fields).<sup class="guide-fn"><a href="#source-13">13</a></sup>

You can also apply labels in Docs/Sheets/Slides (**File** → **Labels**) or from Drive Preview (**More** → **Labels**), and search with **Search in Drive** → **Show search options** → **Labels**.<sup class="guide-fn"><a href="#source-13">13</a></sup>

If you do not see Labels, your admin may not have turned them on — ask them.<sup class="guide-fn"><a href="#source-13">13</a></sup>
