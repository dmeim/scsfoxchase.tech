Need to remove a file from Google Drive? You can move it to **Trash**, empty Trash later, or remove a file you do not own from your Drive view.<sup class="guide-fn"><a href="#source-1">1</a></sup>

## What happens when you delete

When you move a file or folder to Trash, it stays there for **30 days**.<sup class="guide-fn"><a href="#source-4">4</a></sup>

- After 30 days, files are deleted forever.<sup class="guide-fn"><a href="#source-4">4</a></sup>
- If you empty Trash yourself, the file is deleted forever right away.<sup class="guide-fn"><a href="#source-4">4</a></sup>
- Items in Trash still count toward your Google Drive storage until they are deleted forever.<sup class="guide-fn"><a href="#source-4">4</a></sup>

Sharing while a file is in Trash:

- If **you own** the file, people you shared it with can still open it until it is permanently deleted.<sup class="guide-fn"><a href="#source-4">4</a></sup>
- If **you are not** the owner, other people can keep access even if you empty your Trash.<sup class="guide-fn"><a href="#source-4">4</a></sup>

Still need the file back? See [Recover a deleted file in Google Drive](/guide/recover-deleted-file-google-drive).<sup class="guide-fn"><a href="#source-4">4</a></sup>

## Computer (including Chromebook)

### Move a file to Trash (or remove it)

If you own the file, move it to Trash. If someone else owns it, you can only remove it from your Drive — you cannot delete their copy.<sup class="guide-fn"><a href="#source-1">1</a></sup>

1. Go to [drive.google.com](https://drive.google.com).
2. Right-click the file.
3. Click **Move to Trash** (owner), or **Remove** (if someone else owns it).<sup class="guide-fn"><a href="#source-1">1</a></sup>

### Permanently delete from Trash

1. Go to [drive.google.com](https://drive.google.com).
2. On the left, click **Trash**.
3. Make sure there are no files you still want.
4. At the top right, click **Empty trash**, then **Delete forever**.<sup class="guide-fn"><a href="#source-1">1</a></sup>

To permanently delete one file:

1. Open **Trash**.
2. Select the file.
3. At the top, choose **Delete forever**.<sup class="guide-fn"><a href="#source-1">1</a></sup>

Tip: If you want others to keep the file, transfer ownership before you delete it.<sup class="guide-fn"><a href="#source-1">1</a></sup>

### Drive for desktop

If you mirror or stream files between Google Drive and your computer, files you put in Trash are put in Trash everywhere.<sup class="guide-fn"><a href="#source-1">1</a></sup>

If you back up to Google Photos, only photos and videos upload. Deleting images does not sync between your computer and Google Photos.<sup class="guide-fn"><a href="#source-1">1</a></sup>

## Android

If you own the file, you can move it to Trash. If you are not the owner, you do not get a remove option, and others still have access.<sup class="guide-fn"><a href="#source-2">2</a></sup>

### Move a file to Trash

1. Open the **Google Drive** app.
2. At the bottom right, tap **Files**.
3. Next to the file you want to delete, tap **More**
   <img class="guide-inline-icon" src="/guides/delete-files-google-drive/menu-more.png" alt="" width="18" height="18" />.
4. Tap **Remove**.<sup class="guide-fn"><a href="#source-2">2</a></sup>

### Permanently delete one file

1. At the top left, tap **Menu**.
2. Tap **Trash**.
3. Next to the file, tap **More**.
4. Tap **Delete forever**.<sup class="guide-fn"><a href="#source-2">2</a></sup>

### Empty Trash

1. Open **Menu** → **Trash**.
2. Confirm there is nothing you still need.
3. At the top right, tap **More**.
4. Tap **Empty trash**.<sup class="guide-fn"><a href="#source-2">2</a></sup>

## Timing and limits

- Files stay in Trash for **30 days**, then they are deleted permanently.<sup class="guide-fn"><a href="#source-4">4</a></sup>
- Emptying Trash deletes those files forever immediately.<sup class="guide-fn"><a href="#source-4">4</a></sup>
- Trash still uses storage until files are gone forever.<sup class="guide-fn"><a href="#source-1">1</a></sup>

If the file is still in Trash (or you may be able to recover it), see [Recover a deleted file in Google Drive](/guide/recover-deleted-file-google-drive).<sup class="guide-fn"><a href="#source-4">4</a></sup>
