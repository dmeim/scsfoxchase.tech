# New Game Proposals

Proposals for **scsfoxchase.tech** secondary-category expansion.

To add Keep?=Y games from unreviewed sections into a fresh agent chat, copy the prompt in `[ADD-GAMES-FROM-PROPOSALS.md](ADD-GAMES-FROM-PROPOSALS.md)`.

**Criteria used**

- Kid-friendly for roughly grades K–8
- Free browser play
- Single-game / single-activity sites only (no aggregators like Poki, Coolmath, CrazyGames, ABCya hubs)
- Not already in the existing games catalog

**Notes**

- Section titles end with `— Reviewed` or `— Not reviewed`.
- When an agent finishes adding Keep?=Y games for a section, it should change that section’s heading from `— Not reviewed` to `— Reviewed`.
- Agents should ONLY process sections marked `— Not reviewed` (unless the user names specific sections).
- Some categories (Cooking, Battle Royale, FPS / Shooter, Survival, Open World) have fewer strong single-site options; scarcity is noted in those sections.
- Multiplayer /.io titles often include public chat — prefer private rooms or teacher supervision.
- PBS Kids / BBC deep links used here point at a single activity, not a multi-game portal page.
- Review ads, accounts, and chat before adding any title to production.
- For each game, put **Y** (keep) or **N** (skip) in the **Keep?** column. When finished, an agent can re-read this file and collect Y vs N selections.
